MCI (Memory Card Interface) hardware controller.

MCI represents the low-level hardware controller for SD/MMC operations on Phytium SoCs. It manages register access, DMA descriptor chains, PIO transfers, and interrupt handling.

§Transfer Modes

  • DMA Mode: High-performance transfers using chained DMA descriptors
  • PIO Mode: Simple FIFO-based programmed I/O transfers

§Timing

The controller supports multiple timing configurations for different clock speeds:

  • 400 KHz (initialization)
  • 25 MHz (default speed)
  • 50 MHz (high speed)
  • 208 MHz (SDR104 UHS-I)

§IOPAD Integration

The controller optionally manages I/O pad configuration for signal delay tuning at high-speed clock rates.
