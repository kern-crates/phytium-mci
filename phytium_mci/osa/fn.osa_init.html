Function osa_init

pub fn osa_init()
Expand description

Initializes the global memory pool.

This function must be called once at startup before any SD/MMC operations that require DMA buffers.

§Example

ⓘ
use phytium_mci::osa::osa_init;

// Call once during system initialization
osa_init();
